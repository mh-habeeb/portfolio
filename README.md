# Muhammed Habeeb — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Projects

- **AI Command Center** — a concept exploring ways to connect data and surface useful insights.
- **IITM BS Study Helper** — a student-made, unofficial study resource with course notes and practice material. It is a work in progress and has had 20+ users.

## Run locally

Open `index.html` in a browser. The portfolio uses Google Fonts; the browser needs an internet connection to load them. System fonts remain available if they cannot load.

## Publish with GitHub Pages

1. Create a public repository, for example `muhammed-habeeb-portfolio`.
2. Add `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build settings, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will show the published address in that settings page. Open it and check the page on a phone as well as a computer.

Keep the IIT Madras degree marked as **Pursuing** until it is completed. The Study Helper is an independent student project, not an official IIT Madras website. Only publish user numbers you can substantiate, and never commit passwords, API keys, private user data, or analytics secrets.
